車禍有人受傷，你沒停下來處理就走，就可能是肇事逃逸。這個罪不管車禍是誰的錯。很多人是因為「不是我撞他的」「看起來沒怎樣」而離開，結果刑事責任比車禍本身還重。

肇事逃逸的條件和刑度是什麼？

《中華民國刑法》第185條之4第1項規定：

情形 法定刑
駕駛動力交通工具發生交通事故，致人傷害而逃逸 六月以上五年以下有期徒刑
致人於死或重傷而逃逸 一年以上七年以下有期徒刑

要件可以拆成四點：

  1. 駕駛動力交通工具：汽車、機車都算。
  2. 發生交通事故：條文用的是「發生交通事故」，不限於你撞別人；別人撞上你、或因為閃避你而摔倒，也可能包括在內。
  3. 有人受傷或死亡。
  4. 逃逸：沒有停留處理就離開現場。

車禍不是我的錯，離開也有罪嗎？

有。《中華民國刑法》第185條之4第2項規定，駕駛人對於發生交通事故致人死傷「係無過失」者，減輕或免除其刑。

意思是：就算事故完全是對方的責任，你離開現場仍然成立這個罪，只是刑度可以減輕甚至免除。法律要求的是事故發生後留下來，讓傷者得到救護、讓責任可以釐清。

我不知道有人受傷，怎麼辦？

肇事逃逸要有故意，也就是知道發生了事故、可能有人受傷，還是離開。真的完全沒有察覺，不成立這個罪。

但「我不知道」需要客觀情形支持。會被檢視的事實包括：

  • 碰撞的力道和聲音；
  • 車損的位置與程度；
  • 事發後有沒有減速、停車、回頭看；
  • 行車紀錄器與路口監視器的畫面；
  • 事後的行為，例如是否修車、是否主動聯絡警方。

如果事後才發現可能撞到人，應儘快主動向警方說明，並保留行車紀錄器的原始檔案。

肇事逃逸和過失傷害是什麼關係？

車禍本身和離開現場，是分開評價的兩件事：

  • 車禍造成受傷：可能涉及《中華民國刑法》第284條過失傷害罪，不超過一年的有期徒刑，或拘役、罰金（上限十萬元）；致重傷者不超過三年的有期徒刑，或拘役、罰金（上限三十萬元）。造成死亡則是第276條過失致死罪，不超過五年的有期徒刑，或拘役、罰金（上限五十萬元）。
  • 離開現場：第185條之4肇事逃逸罪。

過失傷害依《中華民國刑法》第287條是告訴乃論，對方撤回告訴就可以結束；肇事逃逸不是告訴乃論，和解之後仍會繼續處理。所以常見的結果是：過失傷害的部分和解撤告，肇事逃逸的部分仍被起訴。

肇事逃逸二審可以依刑法第59條撤銷改判嗎？

可能，但不是只要和解就一定減刑。《中華民國刑法》第59條要求犯罪情狀顯可憫恕，而且即使判處法定最低刑仍嫌過重；法院必須把事故責任、傷勢、離場原因、救護義務、賠償履行情形及行為人的個人狀況一起判斷。

臺灣高等法院臺中分院111年度交上訴字第31號刑事判決記載，張榮成律師擔任被告的指定辯護人。二審認為，原判決沒有完整考量被告只是肇事次因、被害人傷勢不重、被告已完成調解賠償，以及身心狀況等個別情形，因此撤銷原判決關於交通事故致人傷害逃逸的部分，依《中華民國刑法》第59條減輕刑度，改判有期徒刑四月，並諭知得易科罰金。

這件裁判仍然認定肇事逃逸罪成立，並不是無罪案例。公開裁判只能證明律師參與及該案的程序結果，也不代表相似案件必然能適用《中華民國刑法》第59條。若傷勢嚴重、駕駛人是主要肇事者、沒有救護或賠償，法院可能作出不同判斷。

發生車禍當下，正確的處理順序是什麼？

  1. 停車，確認有沒有人受傷。
  2. 有人受傷就叫救護車，並報警。
  3. 留在現場等警察，不要因為趕時間或對方說沒事就離開。
  4. 拍照、保存行車紀錄器。
  5. 交換聯絡方式，通知保險公司。

對方說「沒事、你先走」時也要小心。對方事後就醫並報案，你仍可能被通知到案。比較穩妥的做法是報警留下紀錄，或至少取得對方明確表示不需處理的紀錄，再離開。

已經離開了，現在可以做什麼？

  1. 儘快主動聯絡警方：說明時間、地點與經過。
  2. 保存證據：行車紀錄器、當天的行程、車輛狀況，不要先修車或刪檔。
  3. 了解對方傷勢並處理賠償：透過保險公司或適當的管道聯絡。
  4. 做筆錄前先整理事發經過：當時看到什麼、聽到什麼、為什麼離開。

FAQ

常見問題

車禍不是我的錯，我離開也算肇事逃逸嗎？
算。刑法第185條之4第1項處罰的是發生交通事故致人傷亡而逃逸，不以駕駛人有過失為要件。同條第2項規定，駕駛人對於事故致人死傷係無過失者，減輕或免除其刑，但罪名仍然成立。
我當下不知道有人受傷，也會成立嗎？
肇事逃逸是故意犯，須對發生事故致人死傷有所認識。是否知情要從客觀情形判斷，例如撞擊力道、聲響、車損位置、當時有無停車查看。只說不知道而沒有其他情形支持，未必會被採信。
留下電話就離開，可以嗎？
風險很高。對方受傷時，應停留現場、協助就醫並報警，等警察到場處理。只留下聯絡方式就離開，仍可能被認定為逃逸，須依當時是否已採取必要的救護與處理來判斷。
肇事逃逸可以和解撤告嗎？
肇事逃逸不是告訴乃論，和解不會讓案件結束。但與被害人和解、賠償，是檢察官與法院處理時會參考的情形。車禍造成的過失傷害依刑法第287條是告訴乃論，對方撤回告訴後該部分可以終結。
肇事逃逸可以易科罰金嗎？
要看判多重。刑法第185條之4第1項前段的最重本刑為五年，如被判六個月有期徒刑，依刑法第41條第1項得聲請易科罰金；超過六個月就不行。是否准許易科罰金由檢察官於執行時決定。
肇事逃逸二審可以依刑法第59條撤銷改判嗎？
可能，但必須由法院依個案全部情狀判斷。臺灣高等法院臺中分院111年度交上訴字第31號刑事判決，審酌被告僅為肇事次因、被害人傷勢非重、已調解賠償及被告身心狀況等因素，依中華民國刑法第59條減刑，撤銷原判相關部分並改判四月、得易科罰金。
