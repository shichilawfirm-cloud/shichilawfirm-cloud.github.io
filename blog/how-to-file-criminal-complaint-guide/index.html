刑事告訴怎麼提出？報警、告訴狀、委任律師與六個月期限

刑事告訴可由有告訴權人，以書狀或言詞向檢察官、司法警察官提出；委任代理人須附委任書。報案三聯單不當然證明已合法告訴，仍應核對筆錄及告訴意旨。

走出警局後，手上常只多了一張報案三聯單，當事人卻不確定承辦人是否已把「我要追究刑事責任」記進筆錄。提出刑事告訴的重點，在於由有告訴權的人，向法定機關清楚表達追訴意思，並留下可核對的書狀、筆錄、收文日期與證據交付紀錄。

刑事告訴可以向哪個機關提出？

走進警察機關報案時，可以向司法警察官以言詞提出告訴；準備好告訴狀時，也可遞交警察機關或地方檢察署。依《刑事訴訟法》第242條，告訴、告發應以書狀或言詞向檢察官或司法警察官為之；以言詞提出者，應製作筆錄。

坐下製作筆錄時，應把犯罪時間、地點、行為、損害及已知行為人線索說清楚，並明確表達希望依法追訴。完成後要核對筆錄是否符合原意，再保留報案三聯單、受理案件證明、告訴狀副本、收文戳章或掛號回執。三聯單是重要程序資料，但單憑三聯單上的簡短案由，未必能證明特定告訴權人已就每個告訴乃論罪名作成合法告訴。

如果偵查中發現犯罪事實全部或一部屬告訴乃論之罪，卻尚未經合法告訴，《刑事訴訟法》第242條也要求檢察官或司法警察官在被害人或其他有告訴權人到案陳述時，訊問是否提出告訴並記明筆錄。因此，不能只看有沒有三聯單，還要核對筆錄中的身分、犯罪事實與告訴意思。

報警、告訴與告發有什麼不同？

同一個派出所櫃檯，可能同時受理求助、報案、告訴或告發。「報案」是一般人描述向警方反映事情的用語，真正的程序效果仍要看陳述內容屬於告訴、告發，或只是提供資訊。《刑事訴訟法》第232條規定犯罪被害人得為告訴；《刑事訴訟法》第240條則規定，不問何人知有犯罪嫌疑者，均得告發。

拿到受理文件後，應回頭確認自己以何種身分陳述，以及有沒有請求追訴的意思。告訴乃論之罪尤其仰賴有告訴權人依法行使權利；第三人提供線索的告發，不能一概取代被害人或其他有權人的告訴。若筆錄文字含糊，可儘快以書狀補充犯罪事實、告訴意旨及原受理案號，留下可追蹤的收文紀錄。

誰可以提出告訴，家人能代替被害人嗎？

家人陪同被害人到場時，常由其中一人先向警方說明，但陪同或代為敘述不等於當然具有告訴權。《刑事訴訟法》第233條規定，被害人的法定代理人或配偶得獨立告訴；被害人死亡時，該條另列可以告訴的親屬或家屬範圍，告訴乃論之罪並不得違反被害人明示意思。

遇到特定犯罪或身分衝突時，資格還要逐條核對。《刑事訴訟法》第234條對條文明列的犯罪設有特別告訴權人；《刑事訴訟法》第235條處理法定代理人或特定親屬為被告時，其他親屬、家長或家屬得獨立告訴的情形。

碰到告訴乃論之罪無人可行使告訴權，或有權人不能行使時，《刑事訴訟法》第236條規定，檢察官得依利害關係人聲請或依職權指定代行告訴人。這不是家屬自行決定由誰替代，應把身分關係、障礙原因及相關資料交由檢察官依法處理。

可以委任律師提出刑事告訴嗎？

當事人因傷勢、工作或案件複雜而委任律師時，可由代理人提出告訴。《刑事訴訟法》第236條之1規定，告訴得委任代理人為之，但應向檢察官或司法警察官提出委任書狀；檢察官或司法警察官認為必要時，仍可命本人到場。

簽委任書前，應確認委任範圍、案件事實與欲追究的對象。律師可以協助整理時間軸、法律爭點、告訴意旨及證據目錄，不能代替當事人補造未發生的事實。收到傳喚後，也要再確認是本人、代理人或兩者均須到場。

刑事告訴狀要準備哪些內容與證據？

打開空白文件時，可以先把「誰、何時、在哪裡、做了什麼、造成什麼結果」寫完整，再補法律評價。告訴狀通常可依下列項目整理：

  • 告訴人與被告資料：告訴人的姓名、聯絡方式與身分；被告資料不完整時，列出已知姓名、帳號、電話、車牌或其他可辨識線索。
  • 犯罪事實時間軸：按日期說明接觸、行為、損害、發現經過及知悉行為人身分的時間。
  • 告訴意旨：清楚表達請求偵查、依法追訴，避免只寫民事退款、道歉或協商要求。
  • 證據與來源：對話原始檔、匯款明細、契約、照片、錄音、監視器保存線索、醫療或驗傷資料，以及每項資料所要證明的事實。
  • 附件與份數：製作證據清單，影本標號與內文一致；原始檔及原件自行妥善保存，依承辦機關要求提出。

整理手機資料時，別只留下對自己有利的零碎截圖，也不要裁切時間、改檔或重新錄製破壞原始資訊。容易滅失的監視器、平台紀錄與通聯資料，可先看刑事證據如何保全；需由機關調取的資料，則在告訴狀內交代保存位置、期間及與案件的關聯。

提出刑事告訴可以照哪五步進行？

事情剛發生時，資料往往散在手機、紙本與家人手上，可以依五個步驟收束：

  1. 確認告訴權人與罪名方向：先辨識誰是被害人、誰可獨立告訴，以及案件是否可能屬告訴乃論。
  2. 固定時間軸與原始證據：記錄犯罪發生、知悉行為人及資料取得時間，保存原始檔、紙本與交付來源。
  3. 選擇言詞或書面提出：口頭報警要核對筆錄；遞交告訴狀要保留收文、郵寄或轉交紀錄。
  4. 確認告訴意旨已被記載：核對筆錄或書狀是否清楚表達請求追訴，並確認告訴人、案件與對象可以識別。
  5. 持續追蹤案號與通知：保存分案資料、傳票及補件紀錄；搬家或聯絡方式變動時，主動向承辦機關更新。

交件後若收到不起訴處分，救濟另有短期法定期間，可參考不起訴後再議怎麼辦；案件進入法院後，被害人是否可聲請參與訴訟，則見犯罪被害人訴訟參與指南。

六個月告訴期間要從哪一天注意？

翻看行事曆時，不能把所有刑事案件都套入六個月。《刑事訴訟法》第237條規定，告訴乃論之罪應自有告訴權人知悉犯人時起六個月內提出；有數名有權人時，其中一人遲誤期間，效力不及於其他人。

發現帳號、知道真名與取得足以辨識行為人的資料，可能落在不同日期，應把證據來源逐日保存。六個月與追訴權時效的適用範圍、起算點及法律效果不同，完整比較可看六個月告訴期間與追訴權時效差在哪。接近期限時不宜等待所有證據蒐集完畢才處理，可先就已知事實依法提出，再依程序補充。

提告時最常見的例外與風險有哪些？

案件完成和解時，當事人常以為簽字後程序會自動結束。《刑事訴訟法》第238條規定，告訴乃論之罪的告訴人得於第一審辯論終結前撤回告訴，撤回後不得再行告訴；但非告訴乃論之罪是否繼續偵辦，不能只看和解或撤告文字。細節可參考刑事撤告後還會判刑嗎。

寄出告訴狀後，也可能發生管轄移轉、要求補件或本人到場等情況。應持續收取掛號信與傳票，確認案號、股別、承辦機關及陳述是否完整；若涉及數名行為人、數個罪名或不同地點，還要逐項核對告訴範圍，避免把其中一個案號誤認為全部事實都已受理。

FAQ

常見問題

到警局報案，就等於已經提出刑事告訴嗎？
不一定。應確認提出者是否有告訴權、是否明確表達請求追訴之意，以及筆錄如何記載。報案三聯單可證明曾到場報案，卻不當然足以證明每個罪名都已合法告訴。
刑事告訴一定要寫告訴狀嗎？
不用。刑事訴訟法第242條規定，告訴可用書狀或言詞向檢察官或司法警察官提出；以言詞提出時，承辦人員應製作筆錄。
可以委任律師代為提出告訴嗎？
可以。刑事訴訟法第236條之1允許委任代理人提出告訴，但應向檢察官或司法警察官提出委任書狀；必要時，機關仍可命本人到場。
告訴狀不知道被告完整姓名，還能提出嗎？
可先依已知事實及可辨識線索提出，並附帳號、電話、車牌、匯款資料或其他線索。不過資料是否足以特定案件與調查對象，仍應依個案判斷，切勿用猜測填寫身分。
刑事告訴都要在六個月內提出嗎？
不是。刑事訴訟法第237條的六個月期間適用於告訴乃論之罪，自有告訴權人知悉犯人時起算；其他犯罪仍須另看追訴權時效及具體程序。
提告後和解，可以直接不去開庭嗎？
不宜自行不到場。和解、撤回告訴及案件是否繼續偵辦是不同問題；收到傳票仍應依法到場或事先向承辦機關確認，並另核對罪名是否屬告訴乃論。
