手機被扣押沒有固定三個月或六個月返還期限；關鍵在是否仍有證據或沒收必要，可依案件情況聲請發還、暫時發還，或繳納擔保金撤銷扣押。

手機被帶走後，工作聯絡、帳號驗證與日常資料都可能受到影響。許多人聽說「三個月會還」或「六個月可以拿回」，但現行《刑事訴訟法》並沒有這種一到期就自動返還的固定期限。真正要先確認的是扣押原因、案件階段，以及原機是否仍有留存必要。

為什麼手機或財物會被扣押？

依刑事訴訟法第133條，可作為證據或得沒收之物可以扣押；為保全追徵，必要時也得酌量扣押犯罪嫌疑人、被告或第三人的財產。

手機可能因裝置本身、其中資料或與案件的關聯而被認為可作為證據。財物也可能涉及沒收或追徵保全。不同扣押目的會影響後續能否發還，不能只用「鑑識是否完成」一項判斷。

非附隨於搜索的扣押，依刑事訴訟法第133條之1，除以得為證據之物扣押或權利人同意外，原則上應經法官裁定。以同意方式扣押時，執行人員應先告知權利人得拒絕，並把同意記載於筆錄。

手機被扣押多久才會返還？

沒有一律適用的三個月或六個月期限。依刑事訴訟法第142條，扣押物如果已無留存必要，不必等到案件終結，應由法院裁定或檢察官命令發還。

判斷時可先整理：

  1. 手機是由哪個機關、哪一案件扣押。
  2. 扣押目的是證據、沒收，還是追徵保全。
  3. 案件目前在偵查、審判或上訴階段。
  4. 手機是否已完成必要檢視，以及原機是否仍被認為需要留存。
  5. 取回手機的具體需要與權利資料。

只有在「已無留存必要」時，才符合正式發還的核心條件。等待時間長短本身，不會自動取代這項判斷。

正式發還、暫時發還與擔保金有何不同？

三種處理方式的法律效果不同：

方式 核心條件 主要效果
正式發還 扣押物已無留存必要 由法院裁定或檢察官命令發還
暫時發還 所有人、持有人或保管人提出請求，並獲准 取回物品，但可能負保管責任
繳納擔保金撤銷扣押 得沒收或追徵之扣押物，所有人或權利人聲請，且法院或檢察官認為適當 定相當擔保金，繳納後撤銷扣押

依刑事訴訟法第142條，暫時發還可以命聲請人負保管責任，不能把它理解為案件已不再需要該物。正式發還則以無留存必要為前提，兩者不應混在同一項請求中而不說明主次。

可以繳納擔保金讓扣押撤銷嗎？

依刑事訴訟法第142條之1，得沒收或追徵的扣押物，法院或檢察官依所有人或權利人的聲請，認為適當時，得裁定或命令相當擔保金，在繳納後撤銷扣押。

這不是任何手機或扣押物都能直接「付錢換回」。條文限定物品性質、聲請人身分，並保留法院或檢察官對適當性的判斷。聲請時應先釐清扣押目的，避免把擔保金制度誤用在單純證據扣押。

數位鑑識完成後，手機是否必須立即返還？

不一定。鑑識完成可以用來說明資料已經取得，支持重新檢視原機是否還有留存必要；但刑事訴訟法第133條仍允許扣押可為證據或得沒收之物，因此鑑識完成不會自動產生立即發還的效果。

聲請時可以具體說明已完成哪些程序、為何原機不再需要留存，以及長期無法使用手機造成的實際影響。若機關仍認為原機可能需要再查驗、作為證據或涉及沒收，則仍會個別判斷。

要如何準備發還扣押物的聲請？

可以先把聲請內容分成四部分：

  • 扣押物名稱、特徵及扣押案件資訊。
  • 聲請人是所有人、持有人、保管人或權利人的依據。
  • 主張已無留存必要，或請求暫時發還的具體理由。
  • 主要請求與備位方案，例如先請求正式發還，未准時再請求暫時發還。

偵查中通常要先確認承辦檢察署與案號；案件已在法院時，則確認審理法院及股別。若物品是任意交付後被留存，刑事訴訟法第143條規定仍準用扣押物處理規定，不因當初是自行交付就排除發還問題。

扣押物可能被變價嗎？

依刑事訴訟法第141條，得沒收或追徵的扣押物，如果有喪失、毀損、減低價值之虞，或不便保管、保管費用過高，得予變價並保管價金。

因此，對容易貶值、難以保管的物品，處理結果不一定是原物持續留存。聲請前要先確認物品是否仍在、是否已變價，以及目前保管的標的是原物或價金。

判決後扣押物何時返還？

依刑事訴訟法第317條，扣押物未經諭知沒收者，應即發還。但在上訴期間內或案件上訴中，如仍有必要，可以繼續扣押。

因此，一審判決沒有宣告沒收，不等於宣判當天必定能領回。仍須確認判決是否確定、有無上訴，以及機關是否認為上訴期間仍有扣押必要。

若手機或重要財物已影響工作生活，可帶扣押物品目錄、搜索或扣押文件及案件資料，向張榮成律師確認聲請方向，也可參考刑事辯護服務與收到搜索票時應注意什麼。中部地區可聯絡台中西區服務據點或嘉義服務據點。

常見問題

手機扣押滿三個月就必須返還嗎？

不一定。《刑事訴訟法》沒有規定滿三個月或六個月即自動返還，仍須判斷有無留存必要。

鑑識完成後可以立刻拿回手機嗎？

鑑識完成可作為聲請理由，但不等於必然立即返還；仍要確認原機有無證據、沒收或保全必要。

暫時發還後可以自由處分手機嗎？

不宜如此理解。刑事訴訟法第142條規定，暫時發還時得命聲請人負保管責任。

所有人以外的人可以請求暫時發還嗎？

可以。刑事訴訟法第142條列有所有人、持有人或保管人，但是否准許仍須個別判斷。

繳擔保金一定可以撤銷扣押嗎？

不一定。限得沒收或追徵的扣押物，並須由所有人或權利人聲請，經法院或檢察官認為適當。

判決沒有沒收，為何還沒發還？

刑事訴訟法第317條允許在上訴期間或上訴中有必要時繼續扣押，應先確認案件是否確定。

FAQ

常見問題

手機被扣押三個月就一定要返還嗎？
不一定。刑事訴訟法沒有規定手機扣押滿三個月或六個月即當然返還；是否發還，重點是扣押物有無繼續留存、作為證據或沒收的必要。
手機完成數位鑑識後，就一定要立刻返還嗎？
不一定。數位鑑識完成是判斷留存必要性的因素之一，但不等於法院或檢察官必須立即返還；仍須確認原機是否另有證據、沒收或保全必要。
正式發還和暫時發還有什麼不同？
正式發還是因扣押物已無留存必要而解除持有；暫時發還則可能命所有人、持有人或保管人負保管責任，物品仍與案件程序相連。
誰可以聲請暫時發還扣押物？
依刑事訴訟法第142條，扣押物的所有人、持有人或保管人可以提出請求，是否准許仍由法院或檢察官依案件需要判斷。
可以繳錢把扣押撤銷嗎？
刑事訴訟法第142條之1限於得沒收或追徵的扣押物，由所有人或權利人聲請，法院或檢察官認為適當時，得定擔保金，繳納後撤銷扣押。
案件判決後，扣押物一定會返還嗎？
刑事訴訟法第317條規定，未經諭知沒收的扣押物應即發還；但在上訴期間或上訴中如有必要，仍得繼續扣押。
物品是自己主動交給警方，也能聲請發還嗎？
可以檢視。刑事訴訟法第143條規定，任意提出或交付後經留存的物品，準用扣押物處理規定，仍可依是否有留存必要判斷發還。
