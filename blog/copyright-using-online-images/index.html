網路上看得到的圖片，不等於可以自由使用。關於網路圖片，最常聽到三種說法，但都不完全對：

  1. 「沒有浮水印、沒寫版權所有，就可以用。」其實《著作權法》第10條規定，著作人於著作完成時享有著作權。不需要註冊，也不需要加浮水印或寫「版權所有」，創作完成就受保護。
  2. 「只是下載存在電腦，沒有公開，就不算。」其實下載存檔可能就是第3條第1項第5款的「重製」；只是現行第91條第4項另有規定，著作僅供個人參考或合理使用者，不構成著作權侵害。
  3. 「著作權的案子，和解撤告就一定結束。」其實現行第100條雖然規定本章之罪須告訴乃論，但有光碟相關的例外；而且相關條文已修正公布、尚未施行，個案要看行為時的條文。

多數圖片從完成時就有著作權，把它下載、修改、貼到自己的網站或社群，可能同時有刑事責任和民事賠償責任；但是否構成侵權，要看有沒有授權、是不是合理使用。

已經收到律師函或警察通知？先做這五件事

  1. 先不要立刻刪除所有東西，但可以先暫停使用，並保存使用情形的截圖、網址、發布時間。
  2. 整理圖片來源：從哪裡下載、有沒有授權條款、有沒有付費購買或委託創作。
  3. 查清楚對方主張的是哪張圖、哪個使用情形，不要一次承認全部。
  4. 留意對方要求的和解金額與條件，簽署前確認授權範圍、期間、是否包含已經發出去的內容。
  5. 如果是警察通知，見收到警局通知書怎麼辦；如果是檢察官傳票，見收到地檢署傳票怎麼辦。

通常由權利人提出告訴，警察機關或檢察署通知到場說明。不論在台中或嘉義，要到哪個機關、哪一天到場，以通知書記載的承辦機關為準。

下載、截圖、貼文、修圖，在法律上各算哪一種利用？

先講清楚保護範圍。《著作權法》第10條規定，著作人於著作完成時享有著作權；第10條之1規定，著作權的保護只及於「表達」，不及於思想、概念、原理等。所以你可以參考別人圖片裡的想法，但不能直接把他的那張圖拿來用。

法律上，不同的使用方式對應不同的權利，也對應不同的條文。

  • 重製：依第3條第1項第5款，是用印刷、複印、攝影或其他方法，直接、間接、永久或暫時地重複製作。下載圖片存檔、截圖、印出來，都可能算。
  • 公開傳輸：依第3條第1項第10款，是用網路或其他通訊方法向公眾提供或傳達著作內容，包括讓公眾可以在各自選定的時間或地點接收。把圖片放上網站、社群貼文、電商商品頁，常被認為是這一類。
  • 改作：依第3條第1項第11款，是以翻譯、編曲、改寫、拍攝影片或其他方法就原著作另為創作。例如把圖片修圖後再用。
  • 散布：依第3條第1項第12款，是不問有償或無償，將著作原件或重製物提供公眾交易或流通。

拿來做商品廣告和自己學習，合理使用的判斷差在哪？

《著作權法》第65條第1項規定，著作的合理使用，不構成著作財產權的侵害。第2項要求審酌一切情狀，特別是下列四項：

  1. 利用的目的及性質，包括是商業目的，還是非營利教育目的；
  2. 著作的性質；
  3. 所利用的質量，及占整個著作的比例；
  4. 利用結果對著作潛在市場與現在價值的影響。

白話講，用在商品廣告、品牌宣傳，通常比個人學習更容易被認為是商業目的；整張圖原樣使用，比只用一小部分更容易有問題；如果用了以後別人就不用再買原圖，對市場影響就大。以上都不是單獨決定的因素，法院會綜合判斷。

另外，現行第91條第4項明文規定，著作僅供個人參考或合理使用者，不構成著作權侵害。

擅自重製或公開傳輸圖片，刑度是多少？

行為 條文 法定刑
擅自重製 第91條第1項 三年以下有期徒刑、拘役，或科或併科七十五萬元以下罰金
意圖銷售或出租而擅自重製 第91條第2項 六月以上五年以下有期徒刑，得併科二十萬元以上二百萬元以下罰金
以重製於光碟之方法犯前項之罪 第91條第3項 六月以上五年以下有期徒刑，得併科五十萬元以上五百萬元以下罰金
擅自公開傳輸、改作、編輯、出租等 第92條 三年以下有期徒刑、拘役，或科或併科七十五萬元以下罰金
明知是侵權重製物而散布，或意圖散布而公開陳列、持有 第91條之1第2項 三年以下有期徒刑，得併科七萬元以上七十五萬元以下罰金

對照前一節：下載存檔可能是第91條第1項的擅自重製；放上網站或社群，常被認為是第92條的擅自公開傳輸。兩條的法定刑相同。

民事賠償：一萬到一百萬元、最高五百萬元是怎麼來的？

《著作權法》第88條第1項規定，因故意或過失不法侵害他人著作財產權者，負損害賠償責任；數人共同侵害，連帶負責。

依第88條第2項，被害人可依民法的損害賠償規定請求，或請求侵害人因侵害所得的利益。第3項規定，被害人不易證明實際損害額時，可請求法院在一萬元以上一百萬元以下酌定，故意且情節重大的，可增至五百萬元。實際金額由法院決定。

和解、撤回告訴有用嗎？第100條的例外與修法提醒

現行《著作權法》第100條規定，本章之罪須告訴乃論，所以權利人撤回告訴，通常會影響案件的處理。

但同條有例外：犯第91條第3項（以重製於光碟之方法意圖銷售或出租而重製）及第91條之1第3項（散布的侵權重製物為光碟）之罪，不在告訴乃論的範圍。一般在網站或社群使用圖片的情形，通常不涉及光碟，但是否落入例外，仍要看個案事實。

修法提醒：著作權法第91、91-1、100、117條已於民國111年5月4日修正公布，並刪除第98、98-1條，沿革記載施行日期由行政院定之，截至本文整理時尚未施行。依全國法規資料庫顯示的修正條文，第91條、第91條之1刪除光碟加重的規定（第91條的合理使用規定因此移為第3項）；第100條的非告訴乃論例外，改為「就有償提供著作全部原樣利用，致著作財產權人受有新臺幣一百萬元以上之損害」，並列出數位格式重製、意圖營利散布數位格式重製物、擅自公開傳輸三種情形。這些還不是現行規定；個案適用哪一版，以行為時有效的條文為準。

談和解時，可以把授權文件、使用紀錄與對方的要求一起整理好，再請張榮成律師協助確認條件。

FAQ

常見問題

圖片上沒有浮水印，就可以用嗎？
不能這樣判斷。著作權法第10條規定，著作人於著作完成時享有著作權，不以註冊或加浮水印為要件。有沒有授權、是否合理使用，才是判斷重點。
只是下載存在電腦，沒有公開，也算侵權嗎？
可能涉及重製。著作權法第3條第1項第5款的重製包括直接、間接、永久或暫時的重複製作。但現行第91條第4項規定，著作僅供個人參考或合理使用者，不構成著作權侵害。
把別人的圖片貼在自己的網站、粉專或商品頁，會有什麼風險？
可能是公開傳輸。著作權法第3條第1項第10款定義公開傳輸，第92條處罰擅自公開傳輸侵害著作財產權者，處三年以下有期徒刑、拘役，或科或併科七十五萬元以下罰金。
收到盜圖的律師函，和解之後案件就會結束嗎？
現行著作權法第100條規定，本章之罪須告訴乃論，因此和解與撤回告訴會影響案件走向。但犯第91條第3項及第91條之1第3項之罪（重製於光碟、散布光碟重製物）不在此限。
圖片侵權要賠多少錢？
著作權法第88條第3項規定，被害人不易證明實際損害額時，可請求法院依侵害情節在一萬元以上一百萬元以下酌定；故意且情節重大者，賠償額得增至五百萬元。實際金額由法院決定。
