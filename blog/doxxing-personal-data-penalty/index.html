把別人個資貼上網會怎樣？個資法的刑責與賠償

在網路上公開他人個資，若違反個資法第19條或第20條第1項，且意圖不法利益或損害他人而足生損害，依第41條最重可處五年有期徒刑，得併科一百萬元以下罰金。

你屬於哪一種情況？

  • 你貼了（或轉貼了）別人的姓名、電話、住址，現在被檢舉、被提告，或收到警局通知：先看第41條刑責那一節與「如果你是貼文的一方」，再對照五種常見情形的比較表。
  • 你的資料被別人貼上網，想知道能不能告、能不能求償：直接跳到「如果你是被貼個資的一方」，那一節也整理了民事賠償的計算方式。

不論是哪一邊，結論都一樣：把別人的個資貼上網，想讓大家評理或給對方壓力，可能違反《個人資料保護法》，嚴重時最重可處五年有期徒刑。是否構成犯罪，要看有沒有合法的理由和目的、貼出去的內容是什麼，以及有沒有足以損害對方的情形。

名字加電話也算？哪些資料是個資，一般人是否也受規範？

《個人資料保護法》第2條第1款列了很多：姓名、生日、身分證統一編號、護照號碼、特徵、婚姻、家庭、教育、職業、病歷、聯絡方式、財務情況、社會活動，以及其他可以直接或間接識別這個人的資料。

白話說，不只是身分證號碼。名字加上公司名稱、名字加上頭像和住家附近的照片，只要讓人看得出是誰，都可能被算進去。

一般人也受規範。同法第2條第8款規定，「非公務機關」是公務機關以外的自然人、法人或其他團體，所以個人也在範圍內。

不過第51條第1項有兩個排除情形：

  • 自然人為單純個人或家庭活動的目的，而蒐集、處理或利用個人資料；
  • 在公開場所或公開活動中所蒐集、處理或利用，且未與其他個資結合的影音資料。

把資料貼到公開社群想讓不特定人看到，是否還算「單純個人或家庭活動」，常會被拿來討論，要依個案判斷。

資料當初為什麼拿到，決定能不能貼：第19條與第20條第1項

兩個關鍵條文是：

  • 第19條：非公務機關蒐集或處理個資，要有特定目的，並符合法律列出的情形之一，例如法律明文規定、與當事人有契約關係、當事人自行公開或其他已合法公開、經當事人同意、對當事人權益無侵害等。
  • 第20條第1項：利用個資要在蒐集的特定目的必要範圍內，除非有例外，例如經當事人同意、為防止他人權益的重大危害等。

比方說，因為買賣糾紛取得對方的電話，目的是聯絡交易；之後把這支電話貼到群組叫大家去騷擾，就可能超出原本的特定目的。

最重五年徒刑：第41條的三個要件，以及為什麼被害人撤回也未必結束

《個人資料保護法》第41條規定，意圖為自己或第三人不法的利益，或損害他人的利益，而違反第19條、第20條第1項或條文所列的其他個資蒐集利用規定，足生損害於他人者，處不超過五年的有期徒刑，得併科新臺幣一百萬元以下罰金。

幾個要件缺一不可：

  1. 有「不法利益」或「損害他人」的意圖；
  2. 違反上述條文；
  3. 足以對他人造成損害。

第45條規定，個資法刑罰章的罪須告訴乃論，但犯第41條之罪，或對公務機關犯第42條之罪，不在此限。這表示即使被害人事後表示不追究，檢察官仍可能繼續偵辦。

貼姓名電話、貼對話截圖、轉貼、交給警察：五種情形的風險比較

情形 主要風險 要看的重點
貼出對方姓名、電話、住址，呼籲大家去聯絡 個資法第19條、第20條第1項、第41條 取得資料的目的、貼出的目的、是否足生損害
貼對方的對話截圖，內含他人姓名和電話 同上；內容也可能牽涉名譽問題 是否有遮蔽、與主張的關聯
轉貼別人已貼出的個資 個資法第19條、第20條第1項 是否屬公開資料、有無加上指控性文字
把糾紛證據交給警察或法院 通常是為了行使權利 提出的對象與範圍
單純在家人群組分享 第51條第1項第1款可能排除 是否真的屬單純個人或家庭活動

涉及名譽的部分，可參考公然侮辱與誹謗怎麼辦；若貼文帶有威脅語氣，另見恐嚇與威脅訊息怎麼辦。

如果你是貼文的一方：刪文之前，先做這五件事

  1. 先不要再貼、再回、再刪光所有文章：刪除未必能消除已經發生的行為，反而可能被解讀為想隱匿。
  2. 把原貼文、留言、截圖、發文時間先備份，包括你當初為什麼貼的上下文。
  3. 整理資料的來源：這些個資是怎麼取得的、對方有沒有自己公開過、有沒有同意。
  4. 想一想有沒有可以主張的例外：例如第19條第1項所列的當事人自行公開或其他已合法公開、經當事人同意、為增進公共利益所必要等情形，是否適用由檢察官與法院依個案判斷。
  5. 讀清楚通知書，確認是警察、調查機關還是檢察官通知，並記下到場日期，見收到警局通知書怎麼辦。

這類案件通常是被害人向警察機關報案或向地檢署提告，由警察通知被告到場，再由檢察官決定是否起訴。不論在台中或嘉義，要到哪個機關、哪一天到場，以通知書記載的承辦機關為準。

如果你是被貼個資的一方：保存證據、提告與請求賠償

  1. 完整截圖保存，要看得到發文者名稱、網址、時間和被貼出的內容。
  2. 不要自己在原貼文下面反擊，以免情緒性的內容成為對方的證據。
  3. 可考慮向平台檢舉並請求下架，但先保存證據再處理。
  4. 評估是否提告，刑事方面可向警察機關或地檢署提出，民事賠償另外評估。

民事賠償的依據是《個人資料保護法》第29條第1項：非公務機關違反本法，致個資遭不法蒐集、處理、利用或侵害當事人權利者，負損害賠償責任，但能證明沒有故意或過失的除外。同條第2項規定，請求賠償時適用第28條第2項至第6項。依這些規定：

  • 被害人雖非財產上的損害，也得請求賠償相當的金額；名譽被侵害的，並得請求回復名譽的適當處分（第28條第2項）。
  • 被害人不易或不能證明實際損害額時，得請求法院依侵害情節，以每人每一事件新臺幣五百元以上二萬元以下計算（第28條第3項）。
  • 同一原因事實造成多數當事人受害的，合計最高總額以新臺幣二億元為限，但所涉利益超過二億元的，以該所涉利益為限（第28條第4項）。

實際能請求什麼、金額多少，由法院依個案決定。不論你是哪一方，都可以帶著截圖與通知書到台中總所或嘉義分所，和張榮成律師討論。

FAQ

常見問題

我只把對方的名字和電話貼出來，也算個資嗎？
算。個人資料保護法第2條第1款列舉姓名、聯絡方式、職業、財務情況等，以及其他可直接或間接識別個人的資料。多筆資料合在一起，更容易被認為能識別特定人。
我是一般人，不是公司，也適用個資法嗎？
適用。個人資料保護法第2條第8款規定，非公務機關包括公務機關以外的自然人、法人或其他團體。但第51條第1項第1款對單純個人或家庭活動目的的蒐集、處理或利用，另有排除規定。
對方說不追究了，案子就會結束嗎？個資法的罪是告訴乃論嗎？
第41條的罪不是。個人資料保護法第45條規定，本章之罪須告訴乃論，但犯第41條之罪者，不在此限，所以即使被害人沒有提告，檢察官也可能偵辦。
我的個資被貼上網，可以請求賠償嗎？
可以主張。個人資料保護法第29條第1項規定，非公務機關違反本法致個資遭不法蒐集、處理、利用或侵害當事人權利者，負損害賠償責任，但能證明無故意或過失的除外。
對方的個資本來就公開在網路上，我轉貼也有問題嗎？
可能仍有爭議。個人資料保護法第19條第1項第3款、第7款有公開資料的例外，但第7款但書排除當事人有更值得保護的重大利益的情形。是否適用，要看個案與貼文目的。
