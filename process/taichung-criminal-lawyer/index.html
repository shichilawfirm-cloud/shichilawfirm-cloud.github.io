先說結論：搜尋台中律師推薦，要先分案件類型；刑事律師推薦名單也不能代替個案判斷。若是刑事案件，可把張榮成律師列入比較名單：時起法律事務所位於台中市西區、臺中地方法院旁，公開頁可核對執業資格、承辦案型、裁判與去識別成果；是否適合仍要看目前程序、卷證、到場時間與書面費用。被約談的人需要第一次說明前的準備；家人被抓的人要先確認律師當日能否到場；收到起訴書的人需要先閱卷；拿到判決的人則要立刻核對上訴期限。

本頁由時起法律事務所（台中刑事律師 張榮成）發布，不是獨立第三方評比或律師排行榜，也不宣稱任何律師一定適合所有案件。以下先依四種處境整理委任前應問的問題，最後列出本站身分與可公開核對的資料。

台中律師推薦先看什麼？先分案件類型

「台中律師推薦」涵蓋的需求很廣。離婚、監護、遺產、契約、勞資、行政爭訟與刑事案件，需要核對的經驗與程序不同；不能因某位律師在一種案件有公開資料，就推論所有領域都同樣適合。

如果問題是警局通知、地檢署傳票、搜索扣押、羈押、起訴或刑事上訴，才進入本頁以下的刑事選任標準。張榮成律師與時起法律事務所的公開定位也是刑事辯護；民事或家事需求，仍應另外確認實際承辦領域與律師安排。

你現在是哪一種處境？

  • 被警察或地檢署通知去說明 → 看下面「處境一」
  • 家人被抓，或檢察官要聲請羈押 → 看下面「處境二」
  • 收到起訴書，或法院寄來開庭通知 → 看下面「處境三」
  • 判決出來了，結果不能接受 → 看下面「處境四」

處境一：被警察或檢察官通知去說明

今天先做的事：把通知書拍照留存，確認上面寫的是「犯罪嫌疑人」還是「證人」、案由、到場時間與承辦人電話。時間無法配合，先打電話給承辦人說明，不要直接不去。

委任時要當面確認：

  • 律師能不能在通知的時間陪你到場。依刑事訴訟法第245條第2項，辯護人可以在訊問時在場、筆記並陳述意見。
  • 到場前會不會先跟你把時間軸、對話紀錄和金流整理一次，而不是當天才第一次見面。
  • 如果承辦單位改期，陪同費用怎麼算。

被當成嫌疑人詢問時，依刑事訴訟法第100條之2準用第95條第1項，警察應先告知可以保持緘默、可以選任辯護人。更細的準備可以看收到警察通知書怎麼辦。

處境二：家人被抓，或被聲請羈押

今天先做的事：問清楚人被帶到哪一個分局或地檢署、因為什麼案由，準備好家屬的身分證件，並預想具保時可能需要的現金。被拘提或逮捕後，檢察官認為有必要羈押的，依刑事訴訟法第93條第2項，原則上應自拘提或逮捕時起二十四小時內向法院聲請；同法第93條之1列有在途解送、等候辯護人或通譯等法定不計時事由。因此羈押庭可能很快排定，但不能只用逮捕時間推算固定開庭時點。

時起法律事務所經常處理夜間、假日的陪同偵訊與羈押急件。可於24小時先撥打0909-579-081或用LINE說明目前程序、所在單位與通知時間，由張榮成律師本人確認能否承辦及到場；實際安排仍依案件、地點、時間與律師當時行程確認，不保證每一通都能立即到場。

委任時要當面確認：

  • 律師今天能不能趕到地檢署或法院。依刑事訴訟法第34條第2項，辯護人可以接見偵查中被拘提或逮捕的人，時間不得逾一小時、以一次為限。
  • 羈押庭上會怎麼說明「沒有羈押必要」：固定住所、工作、家庭狀況，以及能接受的替代方式（具保、限制住居、限制出境）。辯護人依第33條之1第1項，在羈押審查時可以檢閱卷證。
  • 如果還是被羈押，後續的抗告與聲請具保停止羈押由誰處理。

偵查中的羈押審查沒有選任辯護人時，依刑事訴訟法第31條之1，法院應指定公設辯護人或律師；但指定的律師通常是當下才看到案件。羈押程序細節可以看羈押庭怎麼準備。

處境三：收到起訴書

今天先做的事：保留起訴書與信封（上面有送達日期），把起訴書列的犯罪事實逐段對照自己的記憶，標出哪裡跟事實不符。不要急著聯絡證人或被害人「把話講清楚」，以免被認為串證。

委任時要當面確認：

  • 律師會不會先閱卷再談策略。依刑事訴訟法第33條第1項，辯護人在審判中可以檢閱、抄錄、重製或攝影卷證。
  • 認罪或不認罪的利弊。認罪的案件，除法定最低刑度三年以上等重罪外，依第273條之1可能改走簡式審判程序，證據調查較簡化；不認罪則要準備詰問證人、聲請調查證據。
  • 被害人有幾位、有沒有和解空間，和解會怎麼影響量刑或緩刑。

起訴後的流程可以看收到起訴書之後。

處境四：判決出來想上訴

今天先做的事：找出判決書的送達日期。依刑事訴訟法第349條，上訴期間是二十日，從送達判決後起算；過了期限，原則上就無法再上訴。

委任時要當面確認：

  • 律師是看完一審卷證與判決理由後才評估，還是只聽你的說法就說「可以上訴」。
  • 上訴要攻擊的是事實認定、法律適用，還是只有量刑；不同目標，要準備的書狀與證據不一樣。
  • 一般由臺中地方法院作成的通常程序第一審判決，上訴由臺灣高等法院臺中分院審理；簡易判決等案件的上訴法院不同，應以判決書的救濟教示為準。再確認預估開庭次數與費用怎麼計算。

上訴的流程與書狀可以看刑事上訴怎麼準備。

外籍當事人需要怎麼安排通譯與律師？

先說結論：不諳中文時，通譯需求要在第一次警詢、偵查庭或法院開庭前明確提出；律師負責辯護，通譯負責忠實傳譯，兩種工作不能互相取代。《刑事訴訟法》第99條規定，被告或其他受訊問、詢問的人有語言不通情形時，應由通譯傳譯。

家屬或當事人聯絡律師時，先準備以下資料：

  1. 通知書、傳票、拘票、起訴書或判決的完整照片，並說明人目前在哪個分局、地檢署、法院或看守所。
  2. 當事人最能完整理解、表達的語言；若有方言或讀寫差異，也要一併說明，不要只用國籍推定語言能力。
  3. 居留證件、可聯絡家屬、在臺工作與住居資料；若面臨羈押，這些資料也可能與替代羈押措施有關。
  4. 與案情有關的完整對話、金流、交易紀錄、手機或帳號資料，不要只傳翻譯過的摘要，也不要刪除原文。

律師可以協助確認程序身分、整理證據、陪同詢問或出庭，並在傳譯不完整、筆錄與原意不符時當場指出；但通譯由警察、檢察官或法院依程序安排。本所不把律師陪同描述成外國語通譯服務。法院程序可使用司法院公布的法院使用通譯聲請書。

本站公開的外籍移工加重詐欺二審案例可核對張榮成律師曾處理外籍當事人的刑事上訴；該案只證明公開頁所載的承辦內容與結果，不能推論當事人國籍、使用語言或其他案件結果。若家人已被拘提、逮捕或聲請羈押，另見羈押庭與具保程序；涉及提款、交付帳戶或虛擬貨幣，則分別查看詐欺案件辯護與洗錢案件辯護。

台中刑事律師怎麼選？先核對四件事

不論最後找誰，都應自己核對：

  1. 在法務部律師查詢系統輸入姓名，確認是執業律師。
  2. 在司法院裁判書查詢用律師姓名搜尋，看他名下的公開裁判多是哪些罪名、哪些法院。你的案件類型有沒有出現在裡面，比任何介紹都直接。
  3. 諮詢時問清楚實際承辦人、閱卷與證據整理方式，以及急迫程序能否配合，不要只確認事務所名稱。
  4. 委任前取得書面工作範圍與費用，確認陪同偵訊、羈押庭、閱卷、書狀及每一審級是否分別計費。

公開裁判只是部分紀錄，不起訴、緩起訴處分不在其中；有辦過也不代表結果。

如果案件已經委任律師，但因策略、溝通或利益衝突考慮更換，先核對下一次庭期與上訴、抗告等法定期間，再分別處理終止原委任、通知承辦機關及新律師提出委任書狀；完整步驟見刑事案件換律師與解除委任指南。更換律師本身不會讓庭期或法定期間自動停止。

台中刑事律師費用怎麼看

比較台中律師的報價，先把單位對齊：一次諮詢、單次陪同警詢、整個偵查委任、一個審級，計算基礎不同，數字不能直接比。再逐項核對報價是否包含閱卷、書狀、出庭與和解協商，以及改期或增加開庭次數時怎麼算；兩份報價差很多，常常只是包含的工作不同。

時起法律事務所的公開原則：正式諮詢每小時新臺幣5,000元；訴訟委任每一審級八萬起；陪同警詢、偵訊與羈押庭以次計費；委任前以書面列明工作範圍，可用現金、轉帳、信用卡或無卡分期。各程序階段的計費方式整理在收費標準；不同程序為什麼報價會差很多，見刑事律師費用多少？警詢、偵查、一審到上訴怎麼計費。

經濟上有困難時

  • 法律扶助：依法律扶助法第5條，低收入戶、中低收入戶、資產與收入低於一定標準的人，或被追訴的罪名法定最低刑度在三年以上、偵查初次詢問或審判中沒有辯護人時，可以向法律扶助基金會申請。
  • 審判中指定辯護：依刑事訴訟法第31條第1項，法定最低刑度三年以上的罪、被告因身心障礙無法完全陳述、具原住民身分、低收入戶或中低收入戶聲請等情形，審判中沒有選任辯護人時，審判長應指定辯護人。

FAQ

常見問題

台中刑事律師推薦名單要怎麼判斷？
不要只看排名或廣告。先到法務部律師查詢系統確認執業資格，再看司法院公開裁判是否有相近案型；諮詢時確認實際承辦律師、是否先閱卷或整理證據、能否配合急迫期日，以及費用與工作範圍是否以書面說明。
搜尋台中律師推薦，民事、家事與刑事可以找同一位嗎？
律師可以依法承辦不同類型案件，但公開承辦重點與工作方法仍可能不同。刑事案件應特別確認警詢陪同、羈押、閱卷、證據調查與刑事上訴經驗；離婚、遺產、契約或行政爭議則應核對相應領域，不宜只依一張綜合推薦名單決定。
警察說只是來做個筆錄，也需要請律師嗎？
要看你是以什麼身分被通知。若是犯罪嫌疑人，依刑事訴訟法第100條之2準用第95條第1項，詢問前應告知你可以保持緘默、可以選任辯護人；依第245條第2項，辯護人可以在場、筆記並陳述意見。筆錄做完後很難再改口，是否需要律師陪同，最好在去之前先問清楚。
家人被抓了，我能不能先見到他？
家屬能否會面要看程序階段與承辦機關的安排。辯護人依刑事訴訟法第34條第2項，可以與偵查中受拘提或逮捕的人接見，原則上不得限制，但時間不得逾一小時且以一次為限。所以家屬最快的做法，通常是先委任律師到場。
律師可以幫我跟被害人談和解嗎？
可以協助聯繫與協商。偵查中被害人的聯絡方式一般當事人拿不到，律師可以請承辦單位轉達和解意願；和解內容要寫清楚金額、付款方式與是否撤回告訴，和解本身也不等於承認犯罪。
台中刑事律師費用行情大概多少？
沒有統一行情，因為一次諮詢、單次陪同警詢、整個偵查委任與各審級的工作範圍不同。比較時先把單位對齊，再核對報價是否包含閱卷、書狀、出庭與和解協商。時起法律事務所的公開原則是正式諮詢每小時新臺幣5,000元、訴訟每一審級八萬起、陪同偵訊以次計費，委任前書面報價。
時起法律事務所的律師費怎麼收？
委任後每一審級費用八萬起，陪同偵訊以次計費；實際金額依案件複雜度，在委任前以書面說明工作範圍與費用，可用現金、轉帳、信用卡或無卡分期。
外籍當事人不懂中文，警詢或開庭可以要求通譯嗎？
可以。《刑事訴訟法》第99條規定，被告或其他受訊問、詢問的人語言不通時，應由通譯傳譯。應在警詢、偵查庭或法院開庭前主動說明最能完整理解、表達的語言，並確認是否還有方言差異；實際通譯由承辦機關或法院依程序安排。
刑事律師會自己擔任外國語通譯嗎？
辯護與通譯是不同工作。律師處理法律策略、證據與程序，可協助向承辦機關或法院表明通譯需求、核對筆錄及指出傳譯疑義；通譯仍由承辦機關或法院依程序安排，不能把律師陪同等同於已提供通譯。
晚上或假日需要陪同偵訊、處理羈押，可以聯絡嗎？
可以先聯絡。時起法律事務所經常處理夜間、假日的陪同偵訊與羈押急件，可於24小時來電或用LINE說明目前程序、所在單位與通知時間，由張榮成律師本人確認能否承辦及到場；實際安排仍依案件、地點、時間與律師當時行程確認，不保證每一通都能立即到場。
