3b:T26c3,<p><strong>這篇不是排行榜。</strong>台中有很多刑事律師，哪一位適合你，取決於你現在卡在哪一關。同樣叫「找律師」，被約談的人缺的是說明前的準備，家人被抓的人缺的是今天就能到場的人，拿到判決的人缺的是時間。下面先依處境分開寫，最後才是本所的資料。</p>
<h2 id="s1">你現在是哪一種處境？</h2>
<ul>
<li><strong>被警察或地檢署通知去說明</strong> → 看下面「處境一」</li>
<li><strong>家人被抓，或檢察官要聲請羈押</strong> → 看下面「處境二」</li>
<li><strong>收到起訴書，或法院寄來開庭通知</strong> → 看下面「處境三」</li>
<li><strong>判決出來了，結果不能接受</strong> → 看下面「處境四」</li>
</ul>
<h2 id="s2">處境一：被警察或檢察官通知去說明</h2>
<p><strong>今天先做的事：</strong>把通知書拍照留存，確認上面寫的是「犯罪嫌疑人」還是「證人」、案由、到場時間與承辦人電話。時間無法配合，先打電話給承辦人說明，不要直接不去。</p>
<p><strong>委任時要當面確認：</strong></p>
<ul>
<li>律師能不能在通知的時間陪你到場。依刑事訴訟法第245條第2項，辯護人可以在訊問時在場、筆記並陳述意見。</li>
<li>到場前會不會先跟你把時間軸、對話紀錄和金流整理一次，而不是當天才第一次見面。</li>
<li>如果承辦單位改期，陪同費用怎麼算。</li>
</ul>
<p>被當成嫌疑人詢問時，依刑事訴訟法第100條之2準用第95條第1項，警察應先告知可以保持緘默、可以選任辯護人。更細的準備可以看<a href="/process/police-notice/" rel="noopener noreferrer">收到警察通知書怎麼辦</a>。</p>
<h2 id="s3">處境二：家人被抓，或被聲請羈押</h2>
<p><strong>今天先做的事：</strong>問清楚人被帶到哪一個分局或地檢署、因為什麼案由，準備好家屬的身分證件，並預想具保時可能需要的現金。被拘提或逮捕後，檢察官認為有必要羈押的，依刑事訴訟法第93條第2項，要在二十四小時內向法院聲請，所以羈押庭多半是當天或隔天就開。</p>
<p><strong>委任時要當面確認：</strong></p>
<ul>
<li>律師今天能不能趕到地檢署或法院。依刑事訴訟法第34條第2項，辯護人可以接見偵查中被拘提或逮捕的人，時間不得逾一小時、以一次為限。</li>
<li>羈押庭上會怎麼說明「沒有羈押必要」：固定住所、工作、家庭狀況，以及能接受的替代方式（具保、限制住居、限制出境）。辯護人依第33條之1第1項，在羈押審查時可以檢閱卷證。</li>
<li>如果還是被羈押，後續的抗告與聲請具保停止羈押由誰處理。</li>
</ul>
<p>偵查中的羈押審查沒有選任辯護人時，依刑事訴訟法第31條之1，法院應指定公設辯護人或律師；但指定的律師通常是當下才看到案件。羈押程序細節可以看<a href="/criminal-defense/bail/" rel="noopener noreferrer">羈押庭怎麼準備</a>。</p>
<h2 id="s4">處境三：收到起訴書</h2>
<p><strong>今天先做的事：</strong>保留起訴書與信封（上面有送達日期），把起訴書列的犯罪事實逐段對照自己的記憶，標出哪裡跟事實不符。不要急著聯絡證人或被害人「把話講清楚」，以免被認為串證。</p>
<p><strong>委任時要當面確認：</strong></p>
<ul>
<li>律師會不會先閱卷再談策略。依刑事訴訟法第33條第1項，辯護人在審判中可以檢閱、抄錄、重製或攝影卷證。</li>
<li>認罪或不認罪的利弊。認罪的案件，除法定最低刑度三年以上等重罪外，依第273條之1可能改走簡式審判程序，證據調查較簡化；不認罪則要準備詰問證人、聲請調查證據。</li>
<li>被害人有幾位、有沒有和解空間，和解會怎麼影響量刑或緩刑。</li>
</ul>
<p>起訴後的流程可以看<a href="/process/indictment-received/" rel="noopener noreferrer">收到起訴書之後</a>。</p>
<h2 id="s5">處境四：判決出來想上訴</h2>
<p><strong>今天先做的事：</strong>找出判決書的送達日期。依刑事訴訟法第349條，上訴期間是二十日，從送達判決後起算；過了期限，原則上就無法再上訴。</p>
<p><strong>委任時要當面確認：</strong></p>
<ul>
<li>律師是看完一審卷證與判決理由後才評估，還是只聽你的說法就說「可以上訴」。</li>
<li>上訴要攻擊的是事實認定、法律適用，還是只有量刑；不同目標，要準備的書狀與證據不一樣。</li>
<li>二審由台中高分院審理，開庭次數與費用怎麼計算。</li>
</ul>
<p>上訴的流程與書狀可以看<a href="/process/criminal-appeal-guide/" rel="noopener noreferrer">刑事上訴怎麼準備</a>。</p>
<h2 id="s6">怎麼用公開資料核對一位律師</h2>
<p>不論最後找誰，都可以花三分鐘自己核對：</p>
<ol>
<li>在<a href="https://lawyerbc.moj.gov.tw/" rel="noopener noreferrer">法務部律師查詢系統</a>輸入姓名，確認是執業律師。</li>
<li>在<a href="https://judgment.judicial.gov.tw/FJUD/default.aspx" rel="noopener noreferrer">司法院裁判書查詢</a>用律師姓名搜尋，看他名下的公開裁判多是哪些罪名、哪些法院。你的案件類型有沒有出現在裡面，比任何介紹都直接。</li>
</ol>
<p>公開裁判只是部分紀錄，不起訴、緩起訴處分不在其中；有辦過也不代表結果。</p>
