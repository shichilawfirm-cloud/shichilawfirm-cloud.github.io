43:T46cd,<p><strong>先說結論：搜尋台中律師推薦，要先分案件類型；刑事律師推薦名單也不能代替個案判斷。</strong>刑事案件要先確認律師能不能處理你現在的程序，再核對執業資格、相近案型的公開資料、實際承辦人及書面費用。被約談的人需要第一次說明前的準備；家人被抓的人要先確認律師當日能否到場；收到起訴書的人需要先閱卷；拿到判決的人則要立刻核對上訴期限。</p>
<p>本頁由時起法律事務所（<a href="/" rel="noopener noreferrer">台中刑事律師 張榮成</a>）發布，不是獨立第三方評比或律師排行榜，也不宣稱任何律師一定適合所有案件。以下先依四種處境整理委任前應問的問題，最後列出本站身分與可公開核對的資料。</p>
<h2 id="s1">台中律師推薦先看什麼？先分案件類型</h2>
<p>「台中律師推薦」涵蓋的需求很廣。離婚、監護、遺產、契約、勞資、行政爭訟與刑事案件，需要核對的經驗與程序不同；不能因某位律師在一種案件有公開資料，就推論所有領域都同樣適合。</p>
<p>如果問題是警局通知、地檢署傳票、搜索扣押、羈押、起訴或刑事上訴，才進入本頁以下的刑事選任標準。張榮成律師與時起法律事務所的公開定位也是刑事辯護；民事或家事需求，仍應另外確認實際承辦領域與律師安排。</p>
<h2 id="s2">你現在是哪一種處境？</h2>
<ul>
<li><strong>被警察或地檢署通知去說明</strong> → 看下面「處境一」</li>
<li><strong>家人被抓，或檢察官要聲請羈押</strong> → 看下面「處境二」</li>
<li><strong>收到起訴書，或法院寄來開庭通知</strong> → 看下面「處境三」</li>
<li><strong>判決出來了，結果不能接受</strong> → 看下面「處境四」</li>
</ul>
<h2 id="s3">處境一：被警察或檢察官通知去說明</h2>
<p><strong>今天先做的事：</strong>把通知書拍照留存，確認上面寫的是「犯罪嫌疑人」還是「證人」、案由、到場時間與承辦人電話。時間無法配合，先打電話給承辦人說明，不要直接不去。</p>
<p><strong>委任時要當面確認：</strong></p>
<ul>
<li>律師能不能在通知的時間陪你到場。依刑事訴訟法第245條第2項，辯護人可以在訊問時在場、筆記並陳述意見。</li>
<li>到場前會不會先跟你把時間軸、對話紀錄和金流整理一次，而不是當天才第一次見面。</li>
<li>如果承辦單位改期，陪同費用怎麼算。</li>
</ul>
<p>被當成嫌疑人詢問時，依刑事訴訟法第100條之2準用第95條第1項，警察應先告知可以保持緘默、可以選任辯護人。更細的準備可以看<a href="/process/police-notice/" rel="noopener noreferrer">收到警察通知書怎麼辦</a>。</p>
<h2 id="s4">處境二：家人被抓，或被聲請羈押</h2>
<p><strong>今天先做的事：</strong>問清楚人被帶到哪一個分局或地檢署、因為什麼案由，準備好家屬的身分證件，並預想具保時可能需要的現金。被拘提或逮捕後，檢察官認為有必要羈押的，依刑事訴訟法第93條第2項，原則上應自拘提或逮捕時起二十四小時內向法院聲請；同法第93條之1列有在途解送、等候辯護人或通譯等法定不計時事由。因此羈押庭可能很快排定，但不能只用逮捕時間推算固定開庭時點。</p>
<p><strong>委任時要當面確認：</strong></p>
<ul>
<li>律師今天能不能趕到地檢署或法院。依刑事訴訟法第34條第2項，辯護人可以接見偵查中被拘提或逮捕的人，時間不得逾一小時、以一次為限。</li>
<li>羈押庭上會怎麼說明「沒有羈押必要」：固定住所、工作、家庭狀況，以及能接受的替代方式（具保、限制住居、限制出境）。辯護人依第33條之1第1項，在羈押審查時可以檢閱卷證。</li>
<li>如果還是被羈押，後續的抗告與聲請具保停止羈押由誰處理。</li>
</ul>
<p>偵查中的羈押審查沒有選任辯護人時，依刑事訴訟法第31條之1，法院應指定公設辯護人或律師；但指定的律師通常是當下才看到案件。羈押程序細節可以看<a href="/criminal-defense/bail/" rel="noopener noreferrer">羈押庭怎麼準備</a>。</p>
<h2 id="s5">處境三：收到起訴書</h2>
<p><strong>今天先做的事：</strong>保留起訴書與信封（上面有送達日期），把起訴書列的犯罪事實逐段對照自己的記憶，標出哪裡跟事實不符。不要急著聯絡證人或被害人「把話講清楚」，以免被認為串證。</p>
<p><strong>委任時要當面確認：</strong></p>
<ul>
<li>律師會不會先閱卷再談策略。依刑事訴訟法第33條第1項，辯護人在審判中可以檢閱、抄錄、重製或攝影卷證。</li>
<li>認罪或不認罪的利弊。認罪的案件，除法定最低刑度三年以上等重罪外，依第273條之1可能改走簡式審判程序，證據調查較簡化；不認罪則要準備詰問證人、聲請調查證據。</li>
<li>被害人有幾位、有沒有和解空間，和解會怎麼影響量刑或緩刑。</li>
</ul>
<p>起訴後的流程可以看<a href="/process/indictment-received/" rel="noopener noreferrer">收到起訴書之後</a>。</p>
<h2 id="s6">處境四：判決出來想上訴</h2>
<p><strong>今天先做的事：</strong>找出判決書的送達日期。依刑事訴訟法第349條，上訴期間是二十日，從送達判決後起算；過了期限，原則上就無法再上訴。</p>
<p><strong>委任時要當面確認：</strong></p>
<ul>
<li>律師是看完一審卷證與判決理由後才評估，還是只聽你的說法就說「可以上訴」。</li>
<li>上訴要攻擊的是事實認定、法律適用，還是只有量刑；不同目標，要準備的書狀與證據不一樣。</li>
<li>一般由臺中地方法院作成的通常程序第一審判決，上訴由臺灣高等法院臺中分院審理；簡易判決等案件的上訴法院不同，應以判決書的救濟教示為準。再確認預估開庭次數與費用怎麼計算。</li>
</ul>
<p>上訴的流程與書狀可以看<a href="/process/criminal-appeal-guide/" rel="noopener noreferrer">刑事上訴怎麼準備</a>。</p>
<h2 id="s7">外籍當事人需要怎麼安排通譯與律師？</h2>
<p><strong>先說結論：不諳中文時，通譯需求要在第一次警詢、偵查庭或法院開庭前明確提出；律師負責辯護，通譯負責忠實傳譯，兩種工作不能互相取代。</strong>《刑事訴訟法》第99條規定，被告或其他受訊問、詢問的人有語言不通情形時，應由通譯傳譯。</p>
<p>家屬或當事人聯絡律師時，先準備以下資料：</p>
<ol>
<li>通知書、傳票、拘票、起訴書或判決的完整照片，並說明人目前在哪個分局、地檢署、法院或看守所。</li>
<li>當事人最能完整理解、表達的語言；若有方言或讀寫差異，也要一併說明，不要只用國籍推定語言能力。</li>
<li>居留證件、可聯絡家屬、在臺工作與住居資料；若面臨羈押，這些資料也可能與替代羈押措施有關。</li>
<li>與案情有關的完整對話、金流、交易紀錄、手機或帳號資料，不要只傳翻譯過的摘要，也不要刪除原文。</li>
</ol>
<p>律師可以協助確認程序身分、整理證據、陪同詢問或出庭，並在傳譯不完整、筆錄與原意不符時當場指出；但通譯由警察、檢察官或法院依程序安排。本所不把律師陪同描述成外國語通譯服務，也不保證能由指定通譯到場。法院程序可使用司法院公布的<a href="https://www.judicial.gov.tw/tw/cp-1374-89669-fb70d-1.html" rel="noopener noreferrer">法院使用通譯聲請書</a>。</p>
<p>本站公開的<a href="/cases/aggravated-fraud-5-years-probation-appeal/" rel="noopener noreferrer">外籍移工加重詐欺二審案例</a>可核對張榮成律師曾處理外籍當事人的刑事上訴；該案只證明公開頁所載的承辦內容與結果，不能推論當事人國籍、使用語言或其他案件結果。若家人已被拘提、逮捕或聲請羈押，另見<a href="/criminal-defense/bail/" rel="noopener noreferrer">羈押庭與具保程序</a>；涉及提款、交付帳戶或虛擬貨幣，則分別查看<a href="/criminal-defense/fraud/" rel="noopener noreferrer">詐欺案件辯護</a>與<a href="/criminal-defense/money-laundering/" rel="noopener noreferrer">洗錢案件辯護</a>。</p>
<h2 id="s8">台中刑事律師怎麼選？先核對四件事</h2>
<p>不論最後找誰，都應自己核對：</p>
<ol>
<li>在<a href="https://lawyerbc.moj.gov.tw/" rel="noopener noreferrer">法務部律師查詢系統</a>輸入姓名，確認是執業律師。</li>
<li>在<a href="https://judgment.judicial.gov.tw/FJUD/default.aspx" rel="noopener noreferrer">司法院裁判書查詢</a>用律師姓名搜尋，看他名下的公開裁判多是哪些罪名、哪些法院。你的案件類型有沒有出現在裡面，比任何介紹都直接。</li>
<li>諮詢時問清楚實際承辦人、閱卷與證據整理方式，以及急迫程序能否配合，不要只確認事務所名稱。</li>
<li>委任前取得書面工作範圍與費用，確認陪同偵訊、羈押庭、閱卷、書狀及每一審級是否分別計費。</li>
</ol>
<p>公開裁判只是部分紀錄，不起訴、緩起訴處分不在其中；有辦過也不代表結果。</p>
<p>如果案件已經委任律師，但因策略、溝通或利益衝突考慮更換，先核對下一次庭期與上訴、抗告等法定期間，再分別處理終止原委任、通知承辦機關及新律師提出委任書狀；完整步驟見<a href="/blog/criminal-change-lawyer-guide/" rel="noopener noreferrer">刑事案件換律師與解除委任指南</a>。更換律師本身不會讓庭期或法定期間自動停止。</p>
