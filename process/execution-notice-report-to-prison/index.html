收到地檢署執行傳票怎麼辦？可以延後報到嗎

你打開信箱，看到一張地檢署寄來的執行傳票，上面寫著某一天要到案。判決確定了，可是手上的工作還沒交接，家裡也還有人要照顧。你第一個念頭可能是：能不能晚一點再去？

先說結論：收到地檢署的執行傳票或通知，代表判決已經確定，檢察官要開始執行了。先看清楚上面的日期與到案地點，不要放著不處理。傳喚不到的後果比你想的嚴重，但法律也留了幾個停止執行與替代執行的出口，下面依你最可能遇到的問題逐一說明。

傳票上的日期不到，可能被拘提甚至通緝

《刑事訴訟法》第469條第1項前段規定，受罰金以外主刑的諭知，而未經羈押的人，檢察官於執行時應傳喚；傳喚不到的，應行拘提。同項但書另規定，經諭知死刑、無期徒刑或逾二年有期徒刑，而有相當理由認為有逃亡之虞者，得逕行拘提，也就是不先傳喚。同條第2項並規定，在法定情形下，檢察官也可以逕行拘提，並可以通緝。

所以執行傳票不是建議，而是正式的傳喚。逾期不到，可能從「自己去報到」變成「被抓到案」。通緝後的處理，請看被通緝了怎麼辦。

為什麼是地檢署通知你？判決確定後由檢察官指揮執行

《刑事訴訟法》第456條第1項規定，裁判除關於保安處分者外，原則上於確定後執行。第457條第1項規定，執行裁判原則上由為裁判法院對應的檢察署檢察官指揮；如果是上級法院駁回上訴，同條第2項規定由上級法院對應的檢察署檢察官指揮，但卷宗在下級法院的，依第3項由下級法院對應的檢察署檢察官指揮。第458條規定，指揮執行應以「指揮書」附具裁判書或筆錄的繕本或節本為之。

白話說：判決確定以後，不是法院打電話叫你去關，而是負責執行的檢察官依判決內容發文通知你。你收到的傳票或通知，通常就是這個程序的第一步。到哪個檢察署報到，以傳票或通知上記載的承辦機關為準，未必是你住的地方。人在台中或嘉義、案件卻在外地的，也要在傳票日期前先與承辦單位聯絡，不要自行判斷可以改地點。

判決內容不同，執行方式也不同：

判決內容 常見執行方式 主要條文
有期徒刑、拘役，未被羈押 檢察官傳喚到案，再發監執行 《刑事訴訟法》第469條
六月以下有期徒刑或拘役，符合條件 可能易科罰金，或易服社會勞動 《中華民國刑法》第41條
罰金 依檢察官命令執行，逾期可強制執行 《刑事訴訟法》第470條
受刑人有特定身心或懷孕情形 依檢察官指揮停止執行 《刑事訴訟法》第467條

工作、家庭走不開，可以延後報到嗎？第467條只有四種停止執行

法條沒有寫「可以申請延後幾天」。能停止執行的，是《刑事訴訟法》第467條列的四種情形，受徒刑或拘役諭知的人，依檢察官之指揮，在痊癒或該事故消滅前停止執行：

  1. 心神喪失；
  2. 懷胎五月以上；
  3. 生產未滿二月；
  4. 現罹疾病，恐因執行而不能保其生命。

第468條另規定，因心神喪失或疾病而停止執行的，檢察官得將受刑人送入醫院或其他適當處所。

如果你的狀況不在這四種之內，例如工作、家庭安排，法條沒有保障你可以延後。這時通常只能在傳票日期前，向承辦單位說明並提出佐證，由檢察官決定。

判六月以下，能不能改成易科罰金或社會勞動？

《中華民國刑法》第41條第1項規定，犯最重本刑為五年以下有期徒刑以下之刑的罪，受六月以下有期徒刑或拘役的宣告，得以新臺幣一千元、二千元或三千元折算一日，易科罰金。但易科罰金難收矯正之效或難以維持法秩序的，不適用。

同條第2項規定，依第1項得易科罰金而未聲請易科罰金的，得以提供社會勞動六小時折算一日，易服社會勞動。第3項則是受六月以下有期徒刑或拘役宣告、但不符合第1項易科罰金規定的，也得依同樣標準易服社會勞動。依第4項，因身心健康之關係執行顯有困難，或易服社會勞動難收矯正之效或難以維持法秩序的，不適用社會勞動。第5項規定社會勞動的履行期間不得逾一年；第6項規定無正當理由不履行，情節重大，或期間屆滿仍未履行完畢的，原本屬第2項情形的，應執行原宣告刑或易科罰金；屬第3項情形的，應執行原宣告刑。

另外，《刑事訴訟法》第479條第1項規定，易服社會勞動或易服勞役，由指揮執行的檢察官命令之。換句話說，能不能改做社會勞動，由檢察官依個案決定；易科罰金也是在執行階段處理，通常同樣要向執行檢察官聲請。

不同意檢察官的執行安排，向原判決法院聲明異議

《刑事訴訟法》第484條規定，受刑人或其法定代理人或配偶，以檢察官執行的指揮為不當的，可以向諭知該裁判的法院聲明異議。也就是說，檢察官的決定不是最後一關，但是否有理由，要由法院依個案審查。

聲明異議不是拖延報到的方法。第484條沒有寫提出聲明異議就當然停止執行，所以傳票上的日期仍要先處理，不要因為想聲明異議就不理會傳喚。聲明異議該寫什麼理由、要附什麼資料，建議帶著判決書與傳票給律師看過再決定。

報到日之前，這六件事先處理好

  1. 看執行傳票的日期、機關與到案方式，拍照存檔。
  2. 對照判決書，確認刑度是徒刑、拘役還是罰金，是否有宣告得易科罰金。
  3. 有第467條的情形，立刻備齊診斷證明等文件，在日期前向承辦單位提出。
  4. 想聲請易科罰金或社會勞動，不要等到最後一天，先問清楚要檢附什麼。
  5. 不同意執行安排，可依《刑事訴訟法》第484條向法院聲明異議。
  6. 千萬不要失聯：不理會傳喚，就可能進入拘提、通緝。

判決本身想不想再爭取，要看是否還在上訴期內，見刑事判決不服怎麼上訴。如果是緩刑被撤銷後的執行，見緩刑與緩起訴。傳票、判決書與診斷證明可以一起帶到台中總所或嘉義分所，由張榮成律師在報到日前看過，再決定要向檢察官說明什麼。

FAQ

常見問題

執行傳票上寫的那天，一定要到嗎？
《刑事訴訟法》第469條第1項規定，受罰金以外主刑之諭知而未經羈押者，檢察官於執行時應傳喚；傳喚不到者，應行拘提。日期有困難，應在日期前主動向傳票上的承辦單位說明。
工作交接不完、家裡要安排，可以申請晚一點報到嗎？
法條沒有寫一般性的「延後報到權」。《刑事訴訟法》第467條列了心神喪失、懷胎五月以上、生產未滿二月、現罹疾病恐因執行而不能保其生命四種停止執行情形，依檢察官之指揮停止執行。
可以繳錢代替進去關嗎？
要看刑度與罪名。《中華民國刑法》第41條第1項規定，犯最重本刑五年以下有期徒刑以下之罪，受六月以下有期徒刑或拘役宣告者，得易科罰金；但易科罰金難收矯正之效或難以維持法秩序者，不在此限。
覺得檢察官的執行安排不公平，可以怎麼辦？
《刑事訴訟法》第484條規定，受刑人或其法定代理人或配偶以檢察官執行之指揮為不當者，得向諭知該裁判之法院聲明異議。是否有理由，由法院依個案審查。
只被判罰金，也要理會地檢署的通知嗎？
《刑事訴訟法》第470條第1項、第2項規定，罰金、罰鍰、沒收及沒入之裁判，應依檢察官之命令執行，該命令與民事執行名義有同一之效力。所以罰金不處理，可能被強制執行財產。
